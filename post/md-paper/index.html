md-paper：从AI到word论文的最后一步

现在的 AI 已经很会“写”，但要把修改真正放回论文里，往往还差最后一步：Word 里的 Zotero 引用、图表编号、交叉引用和排版，经不起反复复制粘贴。

md-paper 是我制作的一套论文改稿技能。它先把 Word 原稿转换为 Markdown 真源，再让 AI 在可检查、可追踪的流程中修改，最后重新生成带有 Zotero 活引用域的 Word 论文。

小修可以直接使用 md-iterate；整轮审稿意见或大规模修改，则可以通过 md-triage 整理任务，再交给 md-swarm 批量处理。最后用 md-build 出稿。

它不是让 AI 替你写论文，而是把复制、粘贴、调格式和逐条发命令这些体力活交出去。修改内容仍由作者确认，引用和关键改动也会经过检查。

项目目前已在 GitHub 开源，安装方式和完整说明都在项目主页：

从 GitHub 下载 md-paper

不会使用 Git 的读者，也可以进入项目页面，点击 Code → Download ZIP 直接下载。
